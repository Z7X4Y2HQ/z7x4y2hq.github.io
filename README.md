# Z7X4Y2HQ app hub

Static GitHub Pages landing page for `https://z7x4y2hq.github.io/`.

It is designed to live as `index.html` at the root of the `Z7X4Y2HQ.github.io` repository. The Setlist and Noggin Joggin cards point to their current GitHub Pages URLs. Kanji Helper currently links to its project repository because I could not confirm a deployed Pages URL.

Once the repository exists, enable GitHub Pages for the `main` branch and `/ (root)` in the repository's Pages settings. No build step is required.
