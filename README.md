# Z7X4Y2HQ project index

A React/Vite homepage for the projects linked to this account. It carries over the warm palette, pinned icon rail, horizontal page movement, staggered entrances, and text-marking controls from the older Cool-Ass-Website project. It uses new writing and CSS artwork; it does not reuse that site's story or photographs.

## Develop and publish

```sh
npm install
npm run dev
```

Run `npm run build` before publishing. Vite builds the app, then copies the production page and assets to the repository root so GitHub Pages can serve them from the `main` branch root. Keep the generated root `index.html` and `assets/` folder in the commit.

Setlist and Noggin Joggin open their live Pages sites. Kanji Helper links to its source repository because I haven't confirmed a deployed app URL.
