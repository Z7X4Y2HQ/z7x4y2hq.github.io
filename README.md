# Z7X4Y2HQ portfolio

A responsive React/Vite portfolio for Areeb. It carries over the original Cool-Ass-Website look and structure: Google Sans, warm photo backgrounds, a floating icon rail, horizontal panels on desktop, paper photo frames, animated entrances, and text highlight/underline controls. On phones, the panels stack vertically and the navigation becomes a swipeable top rail.

The page brings over the personal introduction, learning timeline, web and game development tools, photography, and writing milestone, then adds links to Setlist, Noggin Joggin, and Kanji Helper. The original Cool-Ass-Website repository is used as a read-only reference.

## Develop and publish

```sh
npm install
npm run dev
```

Run `npm run build` before publishing. Vite builds the app, then copies the production page and assets to the repository root so GitHub Pages can serve them from the `main` branch root. Keep the generated root `index.html` and `assets/` folder in the commit.

Setlist and Noggin Joggin open their live Pages sites. Kanji Helper links to its source repository because a deployed app URL has not been confirmed.
